# 올바른 매입

부산 현장매입과 부산 외 전국 택배매입을 안내하는 모바일 중심 Next.js 사이트입니다.

## 실행

```bash
npm install
npm run dev
```

## 공개 전 설정

- 사이트맵과 canonical 주소는 기본적으로 `https://macpro.kr`을 사용합니다. 다른 대표 도메인을 사용할 때만 `NEXT_PUBLIC_SITE_URL`을 Vercel 환경 변수로 지정합니다.
- 전화 상담은 `010-6648-4886`으로 연결됩니다. 카카오톡은 링크가 준비될 때까지 비활성 배너로 표시합니다. 사업자 정보, 방문 가능 범위, 택배·검수·정산 조건을 확인해 게시합니다.
- 실제 지역별 사례와 사진을 확보하면 해당 지역 페이지에 추가합니다. 현재 지역 안내는 각 지역의 서비스 방식과 준비 정보에 집중하며, 실적이나 매입 가격을 만들어 내지 않습니다.
