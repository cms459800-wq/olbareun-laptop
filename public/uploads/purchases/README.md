# 부산 매입 현장 사진 업로드

이 폴더에 실제 매입 사진 4장을 숫자 파일명으로 업로드하세요.

- 1.webp (첫 번째)
- 2.webp (두 번째)
- 3.webp (세 번째)
- 4.webp (네 번째)

JPG, JPEG, PNG도 가능합니다. 예: 1.jpg, 2.png, 3.webp, 4.jpg.
확장자가 달라도 숫자 1 → 2 → 3 → 4 순서로 표시됩니다.
같은 번호의 파일은 하나만 올려주세요. 여러 확장자가 있으면 WEBP를 우선합니다.
사진 권장 비율 4:3, 가로 1200px 이상.
업로드한 변경 사항을 GitHub에 저장하면 자동 배포 후 /busan 슬라이드에 반영됩니다.
